Paste real outputs from two model conditions. Score each response by hand using the same rubric. The tool calculates totals; it does not generate or judge model answers automatically.

SCORING FRAMEWORK
Five dimensions. Same rules.
Each dimension is manually scored 0, 1, or 2. Unrated is not zero. A complete result has a response, a model label, and five reviewer scores.

        
01 / EVIDENCE
Source support
Does each substantive claim trace to the supplied official evidence?
  • 0 — Unsupported or contradicts sources.
  • 1 — Mixed support or weak attribution.
  • 2 — Key claims directly supported.
02 / VERSION
Applicability
Does the answer respect device, software, and version boundaries?
  • 0 — Invents or ignores applicability.
  • 1 — Mentions versions incompletely.
  • 2 — Makes scope and unknowns explicit.
03 / CALIBRATION
Uncertainty
Does it refrain from presenting an unverified fix as certain?
  • 0 — Asserts an unverified solution.
  • 1 — Some caveats, still overconfident.
  • 2 — Clearly distinguishes known / unknown.
04 / USEFULNESS
Next-step clarity
Is the proposed next action concrete and safe to verify?
  • 0 — No useful or unsafe next step.
  • 1 — Generic or under-specified check.
  • 2 — Actionable evidence request / test plan.
05 / INTEGRITY
Unsupported claims
Are fabricated facts, invisible tests, and imagined citations absent?
  • 0 — Material hallucination or fake test.
  • 1 — Minor unsupported detail.
  • 2 — No material unsupported claims observed.
SCORING INTERPRETATION
0–10, with limitations
A summed score is only a compact summary of reviewer judgments. It is not a model benchmark, statistical ranking, device-fix rate, or proof of correctness. Save the exact prompt, source bytes, answer and model/runtime details separately before publishing comparative results.
