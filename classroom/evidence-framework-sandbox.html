Framework layer · in scope

Case structure, evidence packet, explicit unknowns, manual comparison, and portable handoff format.

Document-editing layer · separate

Rewriting source documents, document versions, publication workflow and any product-specific behavior belong to a separate implementation.

Optional computational exploration

Review time is limited. Which missing details should the framework verify first? A search lab compares a simple greedy choice against exact subset search using transparent toy data. This is a genuine optimization problem, not a claim of evolutionary or neural-network implementation.
