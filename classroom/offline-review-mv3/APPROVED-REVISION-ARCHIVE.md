# Local reviewed paragraph overlay in an offline ZIP

This optional **Node-only** adapter uses the existing inert mirror and ZIP modules. It does not run inside Chrome, install anything, call a provider, acquire sources or modify the normal capture archive path. Callers supply an independently approved local overlay grant and its expected SHA-256 from a separate trusted review channel; do not derive that pin from the incoming grant.

The grant pins the exact public TechDocs URL and edition, case and run, existing captured paragraph anchor, distinct overlay anchor, canonical normalized capture digest, trusted typed-renderer receipt and independent original/working-copy byte digests, and the specifically approved plain paragraph text. The supplied working-copy bytes are verified, **not parsed or embedded**. The overlay is separately reviewed text, not a claim of stylistic parity or that its text was extracted from the working copy. The package keeps the baseline snapshot paragraph and inserts an inert, escaped addition next to it; its index deep-links to the new archive anchor, and manifest distinguishes content and authority. It does not authenticate reviewers or grant publication rights.

The normal snapshot-byte verifier does not accept an overlay archive. A future CLI must explicitly pass the same reviewed inputs and compare against this builder. The portable fixture uses synthetic source text, grants and receipts; no production revision, real browser or integrated renderer outcome is claimed here. Existing page captures without an exact captured paragraph anchor do not qualify.
