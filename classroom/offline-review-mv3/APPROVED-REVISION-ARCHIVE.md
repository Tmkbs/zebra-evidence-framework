# Local reviewed paragraph overlay in an offline ZIP

This optional **Node-only** adapter uses the existing inert mirror and ZIP modules. It does not run inside Chrome, install anything, call a provider, acquire sources or modify the normal capture archive path. Callers supply an independently approved local overlay grant and its expected SHA-256 from a separate trusted review channel; do not derive that pin from the incoming grant.

The grant pins the exact public TechDocs URL and edition, case and run, existing captured paragraph anchor, distinct overlay anchor, canonical normalized capture digest, trusted typed-renderer receipt and independent original/working-copy byte digests, and the specifically approved plain paragraph text. The supplied working-copy bytes are verified, **not parsed or embedded**. The overlay is separately reviewed text, not a claim of stylistic parity or that its text was extracted from the working copy. The package keeps the baseline snapshot paragraph and inserts an inert, escaped addition next to it; its index deep-links to the new archive anchor, and manifest distinguishes content and authority. It does not authenticate reviewers or grant publication rights.

The normal snapshot-byte verifier does not accept an overlay archive. A future CLI must explicitly pass the same reviewed inputs and compare against this builder. The portable fixture uses synthetic source text, grants and receipts; no production revision, real browser or integrated renderer outcome is claimed here. For version 1 grants, captures without an exact captured paragraph anchor do not qualify.

Version 2 of the same local overlay grant also supports a captured list item whose DOM anchor was not captured. The explicit locator is {section_anchor, block_kind="list_item", section_block_index, block_sha256}. The index is zero-based from the first captured block after the anchored heading; all captured block kinds count, stopping at the next same/higher heading. The locator hash is SHA-256 of the original block's UTF-8 text after collapsing ASCII HTML whitespace (tab, newline, form feed, carriage return and space) and trimming only ASCII space. The exact full native snapshot digest still applies. No anchor is written into the capture, and a truncated capture stays marked truncated. The archive renderer verifies the corresponding escaped emitted list item before inserting an inert addition inside it, leaving other identical text untouched.

Locating an item or rendering a trusted local typed copy does not authorize archiving the overlay. The v2 overlay has its own separately trusted digest and local-only scope. The synthetic fixture independently grants that scope; observed real-source locators alone must not be packaged or published.
