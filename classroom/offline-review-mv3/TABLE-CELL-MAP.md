# Optional local table-cell map
`captureTableActive(chrome, expected, {approved:true})` uses existing active-tab approval and same top-frame/public TechDocs rules. No popup changes and no added permissions. It returns plain `zebra-doc-capture/v1` unchanged plus an optional separate `zebra-table-cell-map/v1`. The map references exact UTF-16 half-open offsets in retained v1 table-row text; it contains no additional source text or HTML, and never splits on a separator found inside a cell. It does not change the native v1 canonical hash.

The map retains at most 32 complete rows of up to 12 unmerged visible, nonempty cells, and omits rows with hidden, partial, merged or outer nested table cells. `omitted_rows` counts retained v1 rows considered but not mapped; it is not a total source-table coverage count. Capture truncation remains separately explicit. The map does not prove exact source-cell equivalence, represent whole tables or authorize a revision. A consumer must independently pin the sidecar with the capture digest and verify the relevant source/anchor and required review before use. No browser installation or real ButtonBar extraction was done.
